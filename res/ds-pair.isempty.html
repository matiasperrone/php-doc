Ds\Pair::isEmpty — Returns whether the pair is empty

Description

public function Ds\Pair::isEmpty(): bool

Returns whether the pair is empty.

Parameters

This function has no parameters.

Return Values

Returns true if the pair is empty, false otherwise.

Examples

Example #1 Ds\Pair::isEmpty() example

<?php
$a = new \Ds\Pair("a", 1);
$b = new \Ds\Pair();

var_dump($a->isEmpty());
var_dump($b->isEmpty());
?>

The above example will output something similar to:

bool(false)
bool(true)
