EventHttp::setAllowedMethods

(PECL event >= 1.4.0-beta)

EventHttp::setAllowedMethods — Sets which HTTP methods are supported in requests accepted by this server, and passed to user callbacks

Description

public function EventHttp::setAllowedMethods( int $methods ): void

Sets which HTTP methods are supported in requests accepted by this server, and passed to user callbacks

If not supported they will generate a "405 Method not allowed" response.

By default this includes the following methods: GET, POST, HEAD, PUT, DELETE. See EventHttpRequest::CMD_* constants.

Parameters

methods

A bit mask of EventHttpRequest::CMD_* constants.

Return Values

No value is returned.
