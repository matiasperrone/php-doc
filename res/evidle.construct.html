EvIdle::__construct — Constructs the EvIdle watcher object

Description

public function EvIdle::__construct( callable $callback , mixed $data = ?, int $priority = ?)

Constructs the EvIdle watcher object and starts the watcher automatically.

Parameters

callback

See Watcher callbacks.

data

Custom data associated with the watcher.

priority

Watcher priority
