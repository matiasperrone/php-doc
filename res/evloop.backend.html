EvLoop::backend

(PECL ev >= 0.2.0)

EvLoop::backend — Returns an integer describing the backend used by libev

Description

public function EvLoop::backend(): int

The same as Ev::backend(), but for the loop instance.

Parameters

This function has no parameters.

Return Values

Returns an integer describing the backend used by libev. See Ev::backend().
