EvLoop::stop

(PECL ev >= 0.2.0)

EvLoop::stop — Stops the event loop

Description

public function EvLoop::stop( int $how = ?): void

Stops the event loop

Parameters

how

One of Ev::BREAK_* constants.

Return Values

No value is returned.
