EvPrepare::__construct

(PECL ev >= 0.2.0)

EvPrepare::__construct — Constructs EvPrepare watcher object

Description

public function EvPrepare::__construct( string $callback , string $data = ?, string $priority = ?)

Constructs EvPrepare watcher object. And starts the watcher automatically. If a stopped watcher is needed, consider using EvPrepare::createStopped()

Parameters

callback

See Watcher callbacks.

data

Custom data associated with the watcher.

priority

Watcher priority
