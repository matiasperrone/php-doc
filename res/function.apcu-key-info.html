apcu_key_info

(PECL apcu >= 4.0.2)

apcu_key_info — Get detailed information about the cache key

Description

function apcu_key_info(string $key): ?array

Get detailed information about the cache key

Parameters

key

The key to retrieve information for.

Return Values

An array containing the detailed information about the cache key, or null if the key does not exist.

Examples

Example #1 A apcu_key_info() example

<?php
apcu_add('a','b');
var_dump(apcu_key_info('a'));
?>

The above example will output:

array(7) {
  ["hits"]=>
  int(0)
  ["access_time"]=>
  int(1606701783)
  ["mtime"]=>
  int(1606701783)
  ["creation_time"]=>
  int(1606701783)
  ["deletion_time"]=>
  int(0)
  ["ttl"]=>
  int(0)
  ["refs"]=>
  int(0)
}
