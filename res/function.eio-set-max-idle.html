eio_set_max_idle

(PECL eio >= 0.0.1dev)

eio_set_max_idle — Set maximum number of idle threads

Description

function eio_set_max_idle(int $nthreads): void

Parameters

nthreads

Number of idle threads.

Return Values

No value is returned.
