ibase_delete_user

(PHP 5, PHP 7 < 7.4.0)

ibase_delete_user — Delete a user from a security database

Description

function ibase_delete_user(resource $service_handle, string $user_name): bool

Parameters

service_handle

The handle on the database server service.

user_name

The login name of the user you want to delete from the database.

Return Values

Returns true on success or false on failure.
