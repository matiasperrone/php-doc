pi

(PHP 4, PHP 5, PHP 7, PHP 8)

pi — Get value of pi

Description

function pi(): float

Returns an approximation of pi. Also, you can use the M_PI constant which yields identical results to pi().

Parameters

This function has no parameters.

Return Values

The value of pi as float.

Examples

Example #1 pi() example

<?php
echo pi(), PHP_EOL; // 3.1415926535898
echo M_PI, PHP_EOL; // 3.1415926535898
?>
