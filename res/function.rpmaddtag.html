rpmaddtag

(PECL rpminfo >= 0.5.0)

rpmaddtag — Add tag retrieved in query

Description

function rpmaddtag(int $tag): bool

Add an additional retrieved tag in subsequent queries.

Parameters

tag

One of RPMTAG_* constant.

Return Values

Returns true on success or false on failure.
