Gmagick::setimageformat — Sets the format of a particular image

Description

public function Gmagick::setimageformat(string $imageFormat): Gmagick

Sets the format of a particular image in a sequence.

Parameters

imageFormat

The image format.

Return Values

The Gmagick object.

Errors/Exceptions

Throws an GmagickException on error.
