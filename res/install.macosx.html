Installation on macOS

Table of Contents

  • Installation on macOS using third-party packages
  • Compiling PHP on macOS
  • Using the bundled PHP prior to macOS Monterey

PHP was bundled with macOS in versions 10 and 11, but is not included in versions since macOS 12 (Monterey). Installation on recent versions either requires using packages from third-party sources, or compilation from source.
