CrudOperationBindable::bind — Bind value to placeholder

Description

abstract public function mysql_xdevapi\CrudOperationBindable::bind(array $placeholder_values): mysql_xdevapi\CrudOperationBindable

Binds a value to a specific placeholder.

Warning

This function is currently not documented; only its argument list is available.

Parameters

placeholder_values

The name of the placeholders and the values to bind.

Return Values

A CrudOperationBindable object.

Examples
