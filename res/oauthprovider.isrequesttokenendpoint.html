OAuthProvider::isRequestTokenEndpoint

(PECL OAuth >= 1.0.0)

OAuthProvider::isRequestTokenEndpoint — Sets isRequestTokenEndpoint

Description

public function OAuthProvider::isRequestTokenEndpoint(bool $will_issue_request_token): void

Warning

This function is currently not documented; only its argument list is available.

Parameters

will_issue_request_token

Sets whether or not it will issue a request token, thus determining if OAuthProvider::tokenHandler() needs to be called.

Return Values

No value is returned.
