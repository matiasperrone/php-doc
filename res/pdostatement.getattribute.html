PDOStatement::getAttribute

(PHP 5 >= 5.1.0, PHP 7, PHP 8, PECL pdo >= 0.2.0)

PDOStatement::getAttribute — Retrieve a statement attribute

Description

public function PDOStatement::getAttribute(int $name): mixed

Gets an attribute of the statement. Currently, no generic attributes exist but only driver specific:

  • PDO::ATTR_CURSOR_NAME (Firebird and ODBC specific): Get the name of the cursor for UPDATE ... WHERE CURRENT OF.

  • Pdo\Pgsql::ATTR_RESULT_MEMORY_SIZE (PostgreSQL specific, available as of PHP 8.4.0): Get the amount of memory, in bytes, allocated to the query result.

Note that driver specific attributes must not be used with other drivers.

Parameters

name

The attribute to query.

Return Values

Returns the attribute value.
