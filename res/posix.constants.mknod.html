posix_mknod() constants

POSIX_S_IFCHR (int)

Character special file

POSIX_S_IFIFO (int)

FIFO (named pipe) special file

POSIX_S_IFREG (int)

Normal file

POSIX_S_IFSOCK (int)

Socket
