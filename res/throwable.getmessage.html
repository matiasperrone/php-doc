Throwable::getMessage

(PHP 7, PHP 8)

Throwable::getMessage — Gets the message

Description

public function Throwable::getMessage(): string

Returns the message associated with the thrown object.

Parameters

This function has no parameters.

Return Values

Returns the message associated with the thrown object.
