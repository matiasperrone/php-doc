Uri\Rfc3986\Uri::getRawHost

(PHP 8 >= 8.5.0)

Uri\Rfc3986\Uri::getRawHost — Retrieve the raw host component

Description

public function Uri\Rfc3986\Uri::getRawHost(): ?string

Retrieves the raw (non-normalized) host component.

Parameters

This function has no parameters.

Return Values

Returns the raw host component as a string if the host component exists, null is returned otherwise.

Examples

Example #1 Uri\Rfc3986\Uri::getRawHost() basic example

<?php
$uri = new \Uri\Rfc3986\Uri("https://example.com");

echo $uri->getRawHost();
?>

The above example will output:

example.com
