Uri\Rfc3986\Uri::getRawPath

(PHP 8 >= 8.5.0)

Uri\Rfc3986\Uri::getRawPath — Retrieve the raw path component

Description

public function Uri\Rfc3986\Uri::getRawPath(): string

Retrieves the raw (non-normalized) path component.

Parameters

This function has no parameters.

Return Values

Returns the raw path component as a string.

Examples

Example #1 Uri\Rfc3986\Uri::getRawPath() basic example

<?php
$uri = new \Uri\Rfc3986\Uri("https://example.com/foo/bar");

echo $uri->getRawPath();
?>

The above example will output:

/foo/bar
