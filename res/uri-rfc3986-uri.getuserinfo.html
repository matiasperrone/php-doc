Uri\Rfc3986\Uri::getUserInfo

(PHP 8 >= 8.5.0)

Uri\Rfc3986\Uri::getUserInfo — Retrieve the normalized userinfo component

Description

public function Uri\Rfc3986\Uri::getUserInfo(): ?string

Retrieves the normalized userinfo component.

Parameters

This function has no parameters.

Return Values

Returns the normalized userinfo component as a string if the userinfo component exists, null is returned otherwise.

Examples

Example #1 Uri\Rfc3986\Uri::getUserInfo() basic example

<?php
$uri = new \Uri\Rfc3986\Uri("https://user:password@example.com");

echo $uri->getUserInfo();
?>

The above example will output:

user:password
