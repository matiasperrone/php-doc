Uri\Rfc3986\Uri::withPath

(PHP 8 >= 8.5.0)

Uri\Rfc3986\Uri::withPath — Modify the path component

Description

public function Uri\Rfc3986\Uri::withPath(string $path): static

Creates a new URI and modifies its path component.

Parameters

path

New path component.

Return Values

The modified Uri\Rfc3986\Uri instance.

Errors/Exceptions

If the resulting URI is invalid, a Uri\InvalidUriException is thrown.

Examples

Example #1 Uri\Rfc3986\Uri::withPath() basic example

<?php
$uri = new \Uri\Rfc3986\Uri("https://example.com/foo/bar");
$uri = $uri->withPath("/baz");

echo $uri->getPath();
?>

The above example will output:

/baz
