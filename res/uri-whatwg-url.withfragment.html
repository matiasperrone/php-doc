Uri\WhatWg\Url::withFragment

(PHP 8 >= 8.5.0)

Uri\WhatWg\Url::withFragment — Modify the fragment component

Description

public function Uri\WhatWg\Url::withFragment(?string $fragment): static

Creates a new URL and modifies its fragment component.

Parameters

fragment

New fragment component.

Return Values

The modified Uri\WhatWg\Url instance.

Errors/Exceptions

If the resulting URL is invalid, a Uri\WhatWg\InvalidUrlException is thrown.

Examples

Example #1 Uri\WhatWg\Url::withFragment() basic example

<?php
$url = new \Uri\WhatWg\Url("https://example.com/#foo");
$url = $url->withFragment("bar");

echo $url->getFragment();
?>

The above example will output:

bar
